# Load06's app

Built at the school exhibition (Nov 10, 2026) from a hand drawing.

**Type:** Game

**What it is:** A beat pad with 12 colorful pads. Each pad plays its own sound when tapped. A play button loops a pattern and there is a tempo slider and a clear button.

Open `index.html` in any browser. It is one file: edit it and make it yours.
